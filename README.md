# 🎁 Amigo Secreto

Bem-vindo ao projeto **Amigo Secreto**! Este aplicativo facilita a organização de sorteios de amigo secreto, permitindo a inclusão de participantes e a realização do sorteio de forma rápida e intuitiva.

## ✨ Funcionalidades
- Adicionar nomes de participantes
- Excluir participantes antes do sorteio
- Realizar o sorteio de maneira justa e aleatória
- Exibir a lista dos pares sorteados
- Interface intuitiva e fácil de usar

## 🚀 Como Usar
1. Clone o repositório:
   ```sh
   git clone https://github.com/seu-usuario/amigo-secreto.git
   ```
2. Acesse o diretório do projeto:
   ```sh
   cd amigo-secreto
   ```
3. Instale as dependências (caso necessário):
   ```sh
   npm install  # ou pip install -r requirements.txt, dependendo da tecnologia
   ```
4. Execute o projeto:
   ```sh
   npm start  # ou python app.py, conforme aplicável
   ```
